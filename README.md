# CLAUDE COSAS

Personal workspace for Claude Code configuration, skills, and project settings.

## Contents

- `CLAUDE.md` - project-level instructions for Claude Code
- `.mcp.json` - MCP server configuration
- `skills-lock.json` - installed Claude Code skills

## Quick start

Install Claude Code, then open this folder as your working directory. Claude will load `CLAUDE.md` automatically on each session.
